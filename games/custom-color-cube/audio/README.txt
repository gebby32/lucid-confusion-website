Drop music files into lucid-radio/ and confusion-radio/, then list them in
stations.json, e.g.:

  { "id": "lucid", "name": "Lucid Radio",
    "tracks": ["lucid-radio/track-01.mp3", "lucid-radio/track-02.mp3"] }

Paths are relative to this folder. MP3, OGG, M4A/AAC and WAV all work in modern browsers.
